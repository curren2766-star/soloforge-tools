# GPU電源診断の判定資料

## 目的と範囲

GPU交換時のPSU総容量と補助電源経路を短時間で確認する初期スクリーニングです。GPUシリーズの公式リファレンス値を使い、個別カードやPSUの動作を保証しません。

## 判定

- 容量不足: 入力PSUがメーカーの推奨システム電力未満。
- 容量要確認: 推奨値は満たすが、CPUクラス加算（高め100W、OC構成200W）後の値に100Wの余裕がない。
- 容量OK: 上記の確認目安に100W以上の余裕がある。
- 8-pin: GPUシリーズの公式必要本数と、PSUから独立して出せるケーブル本数を比較。
- 16-pin: GPUが求める300W / 450W / 600W定格以上のネイティブケーブルだけをOKとする。付属アダプター経路は、本数を満たしても要確認。

総合判定は、どちらかが不足なら「PSU交換候補」、不足がなく要確認があれば「PSU確認必要」、両方OKなら「そのまま交換候補」です。

## 出典

- NVIDIA GeForce公式製品仕様（RTX 50 / 40シリーズ）
- AMD Radeon公式製品仕様（RX 9000 / 7000シリーズ）

各レコードの公式URLは `assets/gpu-data.js` に保持し、結果から直接確認できます。NVIDIAは公式ページの注記どおりメーカー製カードの仕様差があり、AMDを含む個別製品でも購入先ではなく製造元の製品仕様を優先します。
