# 字幕読み速度チェッカーの計算方針

入力文章は前後を `trim()` した後、改行コードを除外する。`Intl.Segmenter("ja", { granularity: "grapheme" })` が利用できる環境では書記素クラスタ単位で数え、非対応環境では `Array.from()` にフォールバックする。文中の空白、句読点、記号、絵文字は表示上の1文字として数える。この方法を字幕規格上の文字数とは扱わない。

CPSは `表示文字数 / 表示秒数`。0〜3.0を「ゆったり」、3.0超〜4.5を「標準的な範囲」、4.5超〜6.0を「やや速め」、6.0超を「かなり速め」とする。判定には丸め前のCPSを使い、表示時だけ小数1桁へ丸める。

表示時間の目安は `max(0.5, 文字数 / 6)` から `max(0.5, 文字数 / 4)` までとし、それぞれ0.1秒単位で切り上げる。これは一般的な参考レンジであり、可読性の保証ではない。

技術的ガードとして表示文字数は1〜5,000文字、表示秒数は0より大きく3,600秒以下の有限数に制限する。不正入力時は直前の結果を非表示にする。
