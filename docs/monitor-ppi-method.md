# モニターPPI比較計算機の計算方針

PPIは `Math.hypot(horizontal_pixels, vertical_pixels) / diagonal_inches`、ピクセルピッチは `25.4 / PPI` で計算する。途中値は丸めず、表示時だけPPIを小数1桁、ピクセルピッチを小数3桁、比較率を小数1桁へ丸める。

比較率は常に現在のモニターAを分母として `(B_PPI / A_PPI - 1) * 100` を使う。相対差が実質ゼロなら「同じ」、絶対値1%未満なら「ほぼ同じ」、それ以外は高い／低いを表示する。

入力は対角インチが0より大きく500以下の有限数、横・縦解像度が1〜100,000の有限整数。空欄では結果を非表示にし、無効値で古い結果を残さない。

PPIはサイズと解像度から求める画素密度であり、画質や見やすさの総合評価ではない。視聴距離、OSスケーリング、パネル品質、リフレッシュレート、視力、用途は別に確認する。
